============================================================

Programming language:

The application should consist of:

1. A server application.
2. A client application.
3. Supporting modules for:

============================================================

Implement genuine socket programming.

The server must:

- create a socket;
- bind to a configurable host and port;

- handle disconnections;
- close resources correctly.

Use appropriate concurrency, such as threads, so that one connected

============================================================

Create a clear application-level protocol operating over the socket

Do not simply send arbitrary strings throughout the application.

Create structured messages for operations.

The protocol should support operations such as:

- CONNECT
- LOGIN
- REGISTER if authentication is implemented
- LIST

Define:

- required parameters;
- optional parameters;
- response;
- error response.

Use a reliable message-framing mechanism.

Remember that TCP provides a byte stream and does not preserve

The implementation must correctly deal with partial reads and writes.

============================================================

Implement real file uploading over the network.

A client must be able to:

For example:

- connection failure;

- server storage error;
- invalid request.
